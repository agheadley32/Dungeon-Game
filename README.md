 # 🗝️ Dungeon Escape

  ## 🎮 Overview
   **Dungeon Escape** is a Java-based adventure game where players explore a randomly generated dungeon, 
                gather magical shards, and escape by assembling the master key.  
                Beware of the undead that lurk in the shadows — and don’t forget to solve the final riddle to truly escape!

   ## 🧩 Gameplay Summary
   1. **Title Screen** – Begin your journey and learn your mission.  
   2. **Random Seed Input** – Enter a seed to generate a unique dungeon layout.  
 3. **Character Selection** – Choose your hero (Warrior, Mage, or Archer).  
4. **Gem Hunt** – Explore the dungeon and collect three hidden gems.  
 5. **Key Assembly** – Combine the shards to form the escape key.  
 6. **Zombie Chase** – Evade the pursuing undead and reach the exit.  
7. **The Riddle** – Solve the final puzzle to win your freedom!

 ## 🛠️ How to Run
   1. Open the project in **IntelliJ IDEA**.  
  2. Run the `Main` class to start the game.  
3. Follow the on-screen instructions to play.  
  4. Input a random seed to generate your dungeon world.
## 🧠 Features
  - Randomly generated dungeon layouts using seed input  
  - Interactive character selection  
  - Real-time exploration and item collection  
  - Dynamic enemy AI (zombie chase sequence)  
  - Final riddle challenge based on sorting algorithms  
  - Clean text-based UI and event-driven gameplay
